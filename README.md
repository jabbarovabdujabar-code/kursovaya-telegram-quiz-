# Курсовой проект: Telegram-бот «Философская викторина»

Сдача в LMS требует 2 ссылки:
1) на документ с курсовой (пояснительная записка)
2) на проект на GitHub

Этот репозиторий — **проект (код)**.

## Требования (соответствие)
Проект реализует вариант «Викторина с вопросами из файла»:
- вопросы загружаются из `src/data/questions.json`
- вопросы задаются последовательно, ведётся счёт
- есть добавление новых вопросов (команда админа)
- используются массивы/объекты/строки
- есть обработка ошибок

## Запуск
1. Установить Node.js (желательно 18+)
2. Установить зависимости:

   npm install

3. Создать файл `.env` в корне проекта:

   BOT_TOKEN=123456:ABCDEF...
   ADMIN_ID=123456789

- `BOT_TOKEN` — токен бота (BotFather)
- `ADMIN_ID` — ваш Telegram user id (нужно для команды добавления вопроса)

4. Запуск:

   npm start

## Команды бота
- `/start` — приветствие
- `/quiz` — начать/продолжить викторину
- `/stats` — статистика
- `/reset` — сброс прогресса
- `/add_question ...` — добавить вопрос (только ADMIN_ID)

### Формат добавления вопроса
Отправьте команду одной строкой:

/add_question Вопрос? | Вариант 1 | Вариант 2 | Вариант 3 | Вариант 4 | 2 | Пояснение почему правильный ответ такой

Где:
- `2` — номер правильного варианта (1..4)

## Данные
- `src/data/questions.json` — база вопросов
- `src/data/sessions.json` — прогресс пользователей (создаётся автоматически)

## Структура
- `src/index.js` — точка входа
- `src/bot/quiz.js` — логика викторины
- `src/storage/questions.js` — чтение/запись базы вопросов
- `src/storage/sessions.js` — хранение прогресса пользователей
- `src/utils/format.js` — вспомогательное форматирование
